# Comments

Comments are preceded by the `#` symbol.

```toy
# This is a comment
```

Comments support markdown formatting, such as **bold** and _italic_. They also support code blocks:

```toy
# ```
# fn example() {
#     # code here
# }
# ```
```

Comments can also include links, such as [this one](https://example.com).
